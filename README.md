# Student Management System

A web-based Student Management System built using Python, Flask, HTML, CSS, and SQLite.

## Features

- Add students
- View student records
- Update student information
- Delete students
- Manage attendance
- Manage marks
- Search/filter student records
- SQLite database
- Sample data generation

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
